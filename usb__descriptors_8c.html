Detailed Description

USB descriptor definitions for TinyUSB.

This file provides the device, configuration, HID, and string descriptors required by TinyUSB for macropad enumeration and communication with the host. It includes descriptor callbacks.

See also
usb_descriptors.h

Based on TinyUSB example code and adapted for this project.
