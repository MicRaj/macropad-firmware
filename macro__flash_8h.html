Detailed Description

Flash memory interface for storing macropad macros.

Author
Michal Rajzer

Provides functions to initialize flash, read and write the macro store, and manage flash memory for persistent macro storage.

Note
Currently uses a fixed flash sector range. Avoid overlapping firmware.
