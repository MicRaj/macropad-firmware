Detailed Description

Main file for the macropad firmware.

Author
Michal Rajzer
Version
0.1
Date
2025-10-08

This file contains the main initialisation and execution loop for the macropad firmware. It performs the following tasks:

  • Initialises hardware and software modules, including GPIO, UART, HID, Flash, and Core functionality.
  • Scans the macropad keys and executes macro sequences.
  • Handles USB communication via TinyUSB, including HID report generation and transmission.
Note
The main loop must not be blocked by long delays or blocking functions. The function tud_task() must be called as frequently as possible within the main loop to ensure responsive USB HID behavior and maintain reliable communication with the host.
