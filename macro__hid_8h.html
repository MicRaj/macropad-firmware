Detailed Description

HID report handling and queue management.

Author

Uses TinyUSB as the USB stack and communicates with the host using the HID protocol.

Sends queued HID reports.

Dequeues the first report and sends it, subsequent reports are sent using the tud_hid_report_complete_cb callback. Should be called frequently in the main loop to ensure responsiveness.
